# إتقان جلوبال — قائمة الإنجاز

## الواجهة الرئيسية والتعريف بالمنصة — مكتمل
- [x] صفحة رئيسية عربية RTL تعرض رؤية المنصة، نطاقها من مصر والسعودية والخليج إلى العالم، ومداخل واضحة لأهم أقسام المنظومة.
- [x] تجربة واجهة أمامية قابلة للعرض ببيانات وحالات تجريبية واضحة، من دون خدمات خلفية أو حسابات أو مدفوعات حقيقية.
- [x] نظام موحد للحالات التفاعلية التجريبية يشمل الأزرار، التبويبات، الفلاتر، النوافذ، والتنبيهات، مع وسم واضح بأنها نسخة عرض.

## التنقل والهوية — مكتمل
- [x] تنقل متجاوب وواضح بين التعليم المدرسي، التعليم الأزهري، أكاديمية القدرات والتحصيلي، السوق، لوحة الطالب، والمساعد الذكي.
- [x] هوية بصرية عربية مع اتجاه RTL وعناصر لونية وطباعية متماسكة تعكس منصة تعليمية موثوقة وحديثة.

## مستعرض المسارات التعليمية — مكتمل
- [x] مستعرض للمسارات التعليمية ببطاقات واقعية وتبويبات وفلاتر للمرحلة، النظام التعليمي، المادة، ونوع المحتوى.
- [x] إبراز مسارات التعليم العام والأزهري مع خرائط ذهنية وبنوك أسئلة وحفظ المتون والقرآن كتجارب عرض.

## أكاديمية القدرات والتحصيلي — مكتمل
- [x] واجهة تدريب تجريبية للقدرات الكمية واللفظية والتحصيلي تتضمن ملخصات أداء.
- [x] إجراء «بدء اختبار» يفتح أسئلة ونتيجة وهمية واضحة مع الحفاظ على وسم نسخة العرض.
- [x] إبراز التدريب المتكيف CAT واستراتيجيات الحل السريع والتجميعات المحدثة كميزات منظومة.

## سوق الخدمات الطلابية — مكتمل
- [x] سوق خدمات طلابي تجريبي لعرض الخدمات البحثية والتعليمية والخصوصية.
- [x] البحث والتصفية وبطاقات مقدمي الخدمة وإجراء «تصفح السوق».
- [x] شرح الضمان المالي والنزاعات مع تمييز جميع الإجراءات المالية بأنها محاكاة غير حقيقية.

## لوحة الطالب والمساعد الذكي — مكتمل
- [x] لوحة متابعة طالب تعرض التقدم، الدروس الأخيرة، المهام، نتائج الاختبارات، الوقت الدراسي، والتوصيات باستخدام بيانات تجريبية.
- [x] نافذة مساعد ذكي سياقي متعددة اللغات بأسلوب سقراطي، مع محادثة تجريبية واقتراحات أسئلة وإجراء فتح/إغلاق المساعد.
- [x] عروض تفاعلية توضح الترجمة والدبلجة الفورية متعددة اللغات من خلال أمثلة قبل/بعد وحالات تشغيل تجريبية.

## الثقة والتحقق — مكتمل
- [x] قسم ثقة يشرح حماية المحتوى والخصوصية والدفع المرن بصياغة توضيحية.
- [x] التحقق من تشغيل المشروع محليًا، وتوفر مسار `/manus-routes.json` الثابت، واستجابة الواجهة الأساسية.

- [x] إضافة مشغل الدروس وأصول فيديو/PDF محلية تجريبية من مجلد `public/demo` مع مسار وصول محمي بالانتساب/الاستحقاق.

## إغلاق وثيقة المواصفات بالكامل — البنود غير القابلة للتجاوز

- [ ] اعتماد نطاق MVP: ثانوي عام/أزهري + معسكر قدرات + سوق مصغر، وتحديد الدول والعملات واللغات الداخلة في الإطلاق.
- [ ] توريد وتوثيق حقوق المناهج والفيديوهات وملفات PDF وبنوك الأسئلة والحلول والخرائط الذهنية، وتعيين مراجعين للمحتوى العام والأزهري والقدرات.
- [ ] بناء لوحة إدارة كاملة للمناهج والوحدات والدروس والموارد والإصدارات والمراجعة والنشر والسحب، مع RBAC وسجل تدقيق.
- [ ] إضافة تخزين ملفات وفيديو خاص، HLS/DRM، روابط موقعة قصيرة العمر، مشغل فعلي، PDF viewer، watermark ديناميكي باسم/هاتف الطالب، وسياسات تنزيل/وصول.
- [ ] استبدال بنك CAT التجريبي ببنك إنتاجي واسع للكمي واللفظي والتحصيلي، مع تصنيف مهاري ومعايرة صعوبة وتحقق خادمي ومؤقت وأقسام وتحليل ضعف وشروحات فيديو.
- [ ] تنفيذ امتحانات K-12 المؤقتة والتصحيح التلقائي والخرائط الذهنية والتقارير على مستوى الوحدة، إضافة إلى مسارات أزهرية فعلية للفقه والتفسير والحديث والتوحيد واللغة والمتون.
- [ ] تنفيذ RAG رأسي: ingestion للنص/PDF/transcript، chunks زمنية، embeddings، Vector DB، citations وtimestamps، وربط الإجابة بالدرس وموضع الفيديو وملف الطالب.
- [ ] إضافة سياسات AI وسلامة ومنع الغش وحصص/تجربة مجانية وقياس جودة الإجابات وتكلفة الاستخدام، مع سجل محادثة قابل للحذف وفق الخصوصية.
- [ ] تنفيذ الترجمة النصية والدبلجة: ASR، subtitles للعربية/الإنجليزية ثم الفرنسية والإندونيسية والأردية والتركية، TTS، voice consent، jobs، مراجعة ومزامنة؛ ثم تقييم lip-sync.
- [ ] تنفيذ تسميع القرآن والمتون والتعرف الصوتي ومخارج الحروف بعد توفير خدمة صوت ومرجع نصي ومعايير اعتماد.
- [ ] تنفيذ سوق إنتاجي: ملفات وتسليم مرحلي، مراجعات، تقييمات، تحقق مقدمي الخدمة، plagiarism check، مركز نزاعات، لجنة مراجعة، إشعارات، وسياسات جودة.
- [ ] اعتماد مزود دفع sandbox ثم تنفيذ Checkout وwebhooks idempotent وsubscriptions/purchases/entitlements، ledger، wallets، escrow، عمولة 10–20%، payouts، refunds، invoices، reconciliation.
- [ ] إضافة بوابات الدفع الإقليمية/العالمية حسب القرار التجاري: Fawry/Vodafone Cash/InstaPay/Meeza، Mada/Apple Pay/STC Pay/Tamara/Tabby، Visa/Mastercard/Stripe/PayPal.
- [ ] تنفيذ باقات شهرية/فصلية/سنوية، شراء دورات، AI Premium Tokens، B2B white-label للمدارس والمعاهد، وقواعد وصول مرتبطة بالدفع.
- [ ] إضافة Analytics events وUTM وleads وcohorts وretention/conversion وCAC/LTV/MRR/ARR/GMV/burn/runway/break-even ولوحة مالية محمية.
- [ ] بناء مسار النمو: محتوى Short-Form، اختبار تشخيصي مجاني، تجربة AI لمدة 7 أيام أو 10 أسئلة، paywall، برنامج سفراء وأكواد إحالة ومجتمعات.
- [ ] إطلاق PWA ثم تطبيق Flutter أو React Native، مزامنة دون اتصال وإشعارات، وبعد إثبات Web MVP إضافة WebRTC/الفصول المباشرة.
- [ ] استكمال الامتثال: حماية القُصّر، الخصوصية، حقوق النشر والصوت، شروط السوق، KYC/AML، الضرائب، سياسة الاسترداد والنزاعات وفحص الانتحال.
- [ ] إضافة semantic cache/حصص للنماذج ومراقبة التكلفة، النسخ الاحتياطي، مراقبة الأداء، سجل أخطاء، اختبارات أمن وصلاحيات واختبارات تكامل للمدفوعات والأصول.
- [ ] تحديث خارطة الطريق التشغيلية 12 شهرًا ومؤشراتها، وتوثيق الميزانية التأسيسية والتوقعات الربعية بعد إدخال بيانات تشغيل حقيقية.
