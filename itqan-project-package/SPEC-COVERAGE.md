## تعريفات الحالة

- **منفذ إنتاجيًا:** تدفق حقيقي بخادم/قاعدة/صلاحيات واختبارات ومصدر بيانات معتمد.
- **جزئي:** يوجد أساس تقني قابل للتوسع، لكنه لا يحقق متطلبات الوثيقة كاملة.
- **تجريبي:** بيانات seed أو واجهة عرض أو fallback؛ لا يجوز احتسابها كإطلاق.
- **غير منفذ:** لا يوجد تدفق قابل للاستخدام خلف الواجهة.
- **محجوب:** يعتمد على حسابات أو محتوى أو حقوق أو قرار من مالك المشروع.

## بوابة الانتقال إلى الإطلاق

لا ينتقل المشروع إلى إطلاق مدفوع أو إعلان «مطابق للوثيقة» قبل إغلاق بنود P0 التالية: محتوى MVP مرخص ومراجع، إدارة أصول ومشغل وحماية، تقييم قابل للتدقيق، RAG رأسي محدود، Checkout/Webhook وledger، دورة Escrow، سياسة خصوصية وحقوق، وسجل أحداث أساسي.
